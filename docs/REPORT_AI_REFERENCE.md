# Report AI 참조 기록

사용자 요청으로 Report AI의 파서·분류·폴더 감시·용어 사전 코드와 테스트를 읽기 전용으로 참고했습니다. 이 앱은 Report AI 실행 환경·운영 DB·PDF·자격 증명에 의존하지 않습니다.

| 참고한 부분 | Evidence Studio에 반영한 범위 |
|---|---|
| corpus_pipeline의 제목·초록 경계 및 문자 품질 판정 | 필요한 순수 함수·상수를 backend/report_metadata.py에 재사용. Report AI를 import하지 않음 |
| 파일 감시·중복·실패 격리 | 60초 감시, 복사 중 파일 확인, SHA-256 정본, 실패 파일 격리와 변경 시 재시도 |
| 다중 분류 축과 fingerprint | 라이브러리·전문가 설정이 분류 캐시를 공유. 같은 축 OR / 축 사이 AND |
| 원천 근거 구조 | 페이지·offset·claim·parameter·수치·조건을 연결하고 raw 표현 보존 |
| 검색 사전 | 대표 용어와 동의어, 승인 상태, revision 충돌 방지, 불변 이력과 보관 상태 |

RapidOCR, 전체 taxonomy 엔진, 자동 후보 수집·검색 실패 분석·복잡한 사전 병합까지 이식한 것은 아닙니다. pypdf로 읽지 못한 페이지는 확인 대상으로 분리합니다. 공개본에 과거 분석 결과나 운영 자료를 포함하지 않습니다.

회귀 기준은 제목에 저자·소속이 섞이는 경우, 글리프 손상, 빈 페이지와 추출 실패의 구분, 동일 경로 내용 변경, 복사 중 파일, 실패 후 다른 파일 처리, 재시작 중복 방지, 수동 교정 이력과 인용 위치 보존입니다.

현재 구조는 [DB 구성](DATABASE_PLAN.md), [전문가 지식](EXPERT_KNOWLEDGE_PLAN.md), [용어 사전](TERMINOLOGY.md)을 참고합니다.
