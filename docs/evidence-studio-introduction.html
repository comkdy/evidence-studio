01 / WHY EVIDENCE STUDIO

연구 판단에 필요한 근거를
빠르게 찾습니다.

흩어진 논문을 반복해서 읽는 부담을 줄이고,
어떤 자료와 조건에 기반한 설명인지 확인합니다.

논문에서 근거까지

제목 검색을 넘어 주장, parameter, 수치와 실험 조건을 함께 살펴보고 원문으로 확인합니다.

담당 지식이 있는 전문가

DRAM, NAND, CIM 등 전문가를 추천받거나 직접 고릅니다. 각 전문가는 연결된 논문과 지식 범위에서 답합니다.

읽을수록 쌓이는 Wiki

논문별 요약을 넘어 개념, 쟁점, 비교 조건을 정리합니다. 새 근거가 들어오면 관련 지식과 이력을 갱신합니다.

03 / QUESTION → EVIDENCE

질문 하나가 답변이 되기까지

현재 질의는 심층 흐름으로 동작합니다.
전체 논문을 매번 읽는 대신 필요한 근거를 선별합니다.

사용자의 질문 예시

“DRAM의 retention을 비교할 때,
어떤 실험 조건을 봐야 할까?”

  1. 전문가 추천 또는 직접 선택

    질문에 맞는 전문가와 지식 범위를 정합니다.

  2. 질문을 나누고 근거 검색

    Wiki·원문·준비된 claim을 keyword/vector로 검색합니다.

  3. 관련 근거 선별과 보완

    Reranker로 정렬하고, 부족한 근거를 추가로 찾습니다.

  4. 종합 답변과 근거 검증

    수치·조건·인용을 연결하고, 확인되지 않은 부분을 밝힙니다.
